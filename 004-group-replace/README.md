# 004 — 同じ置換を 4 つの実行系で書き比べる

対応記事: 正規表現のグループ化と置換

## 動かす

```bash
bash run.sh              # 同じ置換を Python / JavaScript / sed / Rust で実行する
python3 matrix.py        # 番号の呼び出し方で結果がどう割れるかを出す
python3 scope.py         # 既定で何件置換するかの差を出す
python3 bench_capture.py # (?:) にすると速くなるのかを測る
```

`make 004` で 4 本まとめて実行できます。

## 何が出るか

### run.sh

`2026-06-12` を `12/06/2026` に並べ替える置換を 4 つの実行系で実行した結果です。
キャプチャの呼び出し方が `\1` 系と `$1` 系の 2 系統に分かれることが分かります。

### matrix.py

同じ意図の置換テンプレートを 5 通り書き、4 つの実行系にかけた結果を並べます。
番号の直後に何を置くかで結果が割れる条件が出ます（手元の macOS では 5 条件中 3 条件）。
割れ方は「エラーになる」「黙って空になる」「意図せず連結される」の 3 種類に分かれます。

### scope.py

同じ形の日付を 2 つ含む入力に、同じ置換を 4 つの実行系でかけます。**既定で何件
置換するかが割れます**（Python だけが全件、他の 3 つは 1 件目だけ）。全件を明示した
書き方も併記するので、移植するときの対応表として使えます。

### bench_capture.py

キャプチャする `( )` と、しない `(?:)` の実行時間を 3 条件で比べます。
グループ数が少ないパターンと多いパターンで、差の出方が変わります。

## 必要なもの

Python、Node.js、sed（Rust は任意。`rust/` は `cargo run` でビルドされます）
