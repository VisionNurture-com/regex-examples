# 002 — 日本語入力が文字クラスでどう扱われるか

対応記事: 正規表現の文字クラス

## 動かす

```bash
python3 matrix.py      # 文字クラスに日本語を与えた結果の一覧（Python 側）
node matrix.mjs        # 同じ入力を JavaScript にかけた結果（記事 sec03-2 の表）
python3 formcheck.py   # 入力欄の検証方針を 3 つ比べる
```

`make 002` で 3 本まとめて実行できます。

## 何が出るか

### matrix.py

全角数字・丸数字・半角カナ・絵文字・結合文字を、`\d` `[0-9]` `\w` `.` の
4 つの文字クラスにかけた結果の一覧です。Unicode 正規化（NFKC）を通した場合との
比較も出ます。

全角数字が `\d` には一致して `[0-9]` には一致しないことが、
入力欄の「全角で入れたら弾かれた」の正体です。

### formcheck.py

郵便番号の検証を題材に、`[0-9]` だけで書く方針・`\d` で書く方針・
NFKC で揃えてから照合する方針の 3 つを、同じ入力集合にかけて比べます。
利用者の打ち方の揺れ（全角・空白・丸数字）に対して通過件数が 1 / 2 / 5 と分かれ、
「どれが正しいか」ではなく「何を通したいか」を先に決める必要が見えます。

## 必要なもの

Python 3.11 以降
