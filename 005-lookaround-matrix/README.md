# 005 — 使える機能を自分の環境に聞く

対応記事: 正規表現の先読み・後読み

## 動かす

```bash
python3 probe.py    # Python 側だけを手早く調べる
python3 matrix.py   # 7 つの実行系を横断して調べる
python3 port.py     # 後読みが無い実行系へどう書き換えるかを確かめる
```

`make 005` で 3 本まとめて実行できます。

## 何が出るか

### probe.py

先読み・後読み・名前付きキャプチャ・アトミックグループ・所有量指定子などを
実際にコンパイルして、この環境で使えるかどうかを一覧にします。

### matrix.py

同じ機能を Python / JavaScript / Go / Rust / .NET / pcre2grep / grep -E にかけ、
**意図どおりマッチするか**まで確かめた表を出します。判定は 3 段階です。

| 記録 | 意味 |
|---|---|
| OK | 期待した文字列にマッチした |
| NG | コンパイルは通ったが、マッチしない / 別の結果になった |
| ERROR | コンパイルの時点で拒否された |

アトミックグループと所有量指定子には「書けるか」と「戻らないか」の 2 条件を置いています。
書けることと意図どおり動くことは別で、実際に**書けるが戻らない挙動にならない**実行系があります。

実行系が見つからない場合、その列は省略します。

### port.py

後読みを持たない実行系（Go / Rust）へ、同じ意図のパターンをどう移すかを確かめます。
肯定後読みはキャプチャで置き換えられ、置き換えた形は 7 実行系すべてで通ります。
否定後読みは単純に置き換えられないうえ、**数字の途中から始まってしまう**落とし穴も
併せて出します。○ × の判定には `matrix.py` と同じコードを使っています。

## 必要なもの

Python 3.11 以降（アトミックグループと所有量指定子は 3.11 で追加されました）。
`matrix.py` は Node.js / Go / cargo / dotnet / pcre2grep があれば、その列も一緒に出します。
