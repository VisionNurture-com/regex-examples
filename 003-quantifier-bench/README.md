# 003 — 量指定子の実行時間を測る

対応記事: 正規表現の量指定子

## 動かす

```bash
python3 ../tools/env_report.py   # 環境情報を先に記録する
python3 bench.py                 # 3 つの書き方の実行時間を比べる
python3 why.py                   # 条件を分けて弱点の場所を切り分ける
python3 extract.py               # 取り出した結果そのものの違いを見る
```

`make 003` で 3 本まとめて実行できます。

## 何が出るか

| スクリプト | 出るもの |
|---|---|
| `bench.py` | `<.*>`（貪欲）・`<.*?>`（最短）・`<[^>]*>`（否定文字クラス）を同じ入力にかけた実行時間。タグの中身と後続テキストの長さを 4 段階で振ります |
| `why.py` | 中身だけ / 後続だけを片方ずつ伸ばした結果（実験 A / B）と、`>` が無い入力で伸ばした結果（実験 C）。どちらの書き方がどの条件に弱いかが分かれ、マッチしない入力では否定文字クラスの優位が消えます |
| `extract.py` | 1 行に同じ形が複数並ぶログから全件取り出したときの、件数・中身・実行時間。書き方によって**結果そのもの**が変わります |

測定結果は `../tools/results/` に環境情報つきで保存されます（`003-quantifier-bench.json` /
`003-quantifier-why.json` / `003-quantifier-extract.json`）。

## 測り方

ウォームアップ 2 回のあと 7 回計測し、**最小値**で比較します
（他プロセスの影響は上振れとして出るため）。中央値も JSON に残ります。

`extract.py` の実験 E は時間ではなく取得件数を見るため、計測は行いません。

## 必要なもの

Python 3.11 以降
